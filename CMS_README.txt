НЕПУТЁВКИ — редактор Pages CMS

1. Загрузите ВСЕ файлы этого архива в корень репозитория GitHub, включая .pages.yml и папку content.
2. Откройте app.pagescms.org и репозиторий murmansk_neputevki.
3. Откройте раздел «Настройки тура». Изменения в content/site.json публикуются через GitHub/Cloudflare.
4. Не удаляйте и не переставляйте активности, пока не обновим сохранение выбора: сейчас выбор запоминается по индексам.
5. Для изменения расположения элементов/дизайна нужен редактор кода либо отдельный визуальный builder; Pages CMS редактирует контент.
6. Цены 59 000 и остальные — ДЕМО, не утверждены.
7. Для просмотра локально используйте сервер (например python -m http.server), а не двойной клик на index.html.
